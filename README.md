# Fundamentos de IA Generativa - Universia

Bem-vindo ao repositório do curso de Fundamentos de IA Generativa da Universia! 🚀

Este repositório contém todos os materiais, projetos e certificados relacionados ao aprendizado de Inteligência Artificial Generativa.

## 📂 Estrutura do Repositório

### 📂 prompts/
Arquivos de texto com os melhores prompts que você testou durante o curso. Aqui você encontrará exemplos práticos de prompts eficazes para diferentes casos de uso.

### 📂 projetos/
Aplicações práticas, códigos e notebooks desenvolvidos durante o curso. Esta pasta contém projetos hands-on que demonstram a aplicação dos conceitos aprendidos.

### 📂 certificados/
Pasta para armazenar o PDF ou imagem do certificado quando concluir o curso.

## 🎯 Objetivo

Este repositório serve como portfólio de aprendizado e documentação do progresso no curso de Fundamentos de IA Generativa, facilitando o acompanhamento e a organização dos materiais estudados.

## 📝 Como Usar

1. Adicione seus prompts testados na pasta `prompts/`
2. Desenvolva e documente seus projetos na pasta `projetos/`
3. Ao concluir o curso, adicione seu certificado na pasta `certificados/`
