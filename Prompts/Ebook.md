# 📘 Ebook: Destravando a Lógica – O Manual Prático de Algoritmos

Este documento consolida a estratégia de **Engenharia de Prompt** utilizada para a concepção, redação e identidade visual do manual. O projeto foca em transformar conceitos complexos de Ciência da Computação em uma linguagem acessível e visual.

---

## 💡 1. Ideação e Estrutura Pedagógica (Gemini)

| Objetivo | Prompt Estratégico |
| :--- | :--- |
| **Naming & Subtítulo** | [cite_start]"Atue como um educador técnico e copywriter. Gere um nome para um ebook de lógica de programação para iniciantes. **Critérios:** 1. Deve usar um verbo de ação (ex: 'Destravar'); 2. O subtítulo deve prometer um método prático e direto; 3. O tom deve ser encorajador." [cite: 12, 13] |
| **Sumário Didático** | [cite_start]"Crie a estrutura de capítulos para um manual de lógica. Divida em 4 pilares essenciais: introdução aos algoritmos, armazenamento de dados, fluxo de decisão e reutilização de código. Use metáforas do cotidiano." [cite: 22, 74, 110, 151] |

## 🎨 2. Identidade Visual (Gemini/GPT)

| Objetivo | Prompt Estratégico |
| :--- | :--- |

Estilo visual limpo e inspiração em arte tech futurista." [cite: 12] |

## ✍️ 3. Redação e Storytelling (Gemini)

| Objetivo | Prompt Estratégico |
| :--- | :--- |
| **Geração de Conteúdo Base** | [cite_start]"Atue como um especialista em didática de computação. Escreva o conteúdo principal para um ebook dividido em 4 capítulos: 1. O que é algoritmo; 2. Variáveis e tipos de dados; 3. Estruturas de controle (Se/Enquanto); 4. Funções. Use uma linguagem que remeta a um manual prático e acessível." [cite: 40, 48, 87, 123, 163] |
