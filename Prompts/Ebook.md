# 📘 Ebook: Destravando a Lógica – O Manual Prático de Algoritmos

Este documento consolida a estratégia de **Engenharia de Prompt** utilizada para a concepção, redação e identidade visual do manual. O projeto foca em transformar conceitos complexos de Ciência da Computação em uma linguagem acessível e visual.

---

## 💡 1. Ideação e Estrutura Pedagógica (Gemini)

| Objetivo | Prompt Estratégico |
| :--- | :--- |
| **Naming & Subtítulo** | "Atue como um educador técnico e copywriter. Gere um nome para um ebook de lógica de programação para iniciantes. **Critérios:** 1. Deve ser um nome curto e marcante que chame a atenção do leitor; 2. O subtítulo deve prometer um método prático e direto; 3. O tom deve ser encorajador." |
| **Sumário Didático** | "Crie a estrutura de capítulos para um manual de lógica. Divida em 4 pilares essenciais: introdução aos algoritmos, armazenamento de dados, fluxo de decisão e reutilização de código. Use metáforas do cotidiano." |

---

## 🎨 2. Identidade Visual (Gemini/GPT)

| Objetivo | Prompt Estratégico |
| :--- | :--- |
| **Capa Principal** | "Crie uma ilustração vetorial moderna. No centro, um jovem em posição de meditação com ícones de código e luzes fluindo de sua mente.Texto no centro horizontal na parte inferior 'Destravando a Lógica'e subtítulo 'O manual prático de algoritmos. Estilo visual limpo e inspiração em arte tech futurista." |
| **Capas de Capítulos** | "Gere 4 imagens minimalistas (9:16) com fundo de malha digital com base no contexto de cada caítulo:O Que é um Algoritmo?, Variáveis e Dados , Controlando o Fluxo,Funções"  |

---

## ✍️ 3. Redação e Storytelling (Gemini)

| Objetivo | Prompt Estratégico |
| :--- | :--- |
| **Geração de Conteúdo Base** | "Atue como um especialista em didática de computação. Escreva o conteúdo principal para um ebook dividido em 4 capítulos: 1. O que é algoritmo; 2. Variáveis e tipos de dados; 3. Estruturas de controle (Se/Enquanto); 4. Funções. Use uma linguagem que remeta a um manual prático e acessível." |
| **Introdução Narrativa** | "Escreva uma introdução curta levando em conta o contexto do ebook sobre intradução a algoritmos na computação. Tom instigante e simplificado." |
| **Explicação Técnica** | "Aja como um escritor. Explique os temas usando analogias e linguagem simplificada. Faça uso de exemplos e situações do cotidiano'." |
